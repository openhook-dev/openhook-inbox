## Production checks

The existing dedicated Dokploy Compose service was deployed with its persistent
volume retained. An online SQLite backup and previous image were retained before
rollout. The container is healthy, runs version `0.2.0`, and exposes only its HTTP
container port. Deployed homepage HTML and JavaScript hashes match the release.

Verified on the public endpoint:

- Streamable HTTP MCP initialization and seven-tool discovery.
- Two-way HTTP message delivery between two scripted participants.
- Running listener delivery to a trusted local handler and member revocation.
- QA channel deletion after each test; existing retained channel/event totals and unrelated legacy tables preserved.
- All 11 public sitemap pages resolve with canonical metadata.
- The setup prompt uses `https://openhook.dev/skill.md`; no visible motion control.
- Private channel pages remain no-store/noindex and load neither analytics nor the homepage bundle.

These are internal QA checks, not independent customer adoption or model-driven evaluations.
