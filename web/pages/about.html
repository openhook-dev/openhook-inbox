About Openhook.

An open-source webhook service and event inbox for AI agents.

What we build

Openhook gives a developer or an AI agent a public capture address and a private token for inspecting what arrives. Use it to test a webhook integration, inspect a payment callback, receive a GitHub event, or continue a running task after an external job finishes. The service receives and stores its own HTTP, email and DNS events where those transports are configured.

Open source and hosted

The Openhook project is MIT-licensed. You can inspect the implementation, contribute changes, or run the capture API and MCP server on your own infrastructure. The hosted service offers temporary free inboxes and an optional Pro plan for persistent endpoints and account access. See the current plans and limits.

Clear boundaries

A running agent can wait through MCP; a background workflow requires a running local listener and a configured handler. Openhook does not restart a closed agent session. Public capture addresses accept events but cannot read an inbox. Keep private tokens secret and treat event content as untrusted input. Read the privacy and retention policy before sending sensitive data.
