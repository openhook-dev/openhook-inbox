Connect your agent.

Add the MCP endpoint. Create your first inbox in the next tool call.

Claude Code

claude mcp add --transport http openhook {{origin}}/mcp

Cursor

Add this to .cursor/mcp.json, then enable Openhook in your tools.

{
  "mcpServers": {
    "openhook": { "url": "{{origin}}/mcp" }
  }
}

VS Code

Save this in .vscode/mcp.json. Start Openhook from the MCP server list.

{
  "servers": {
    "openhook": { "type": "http", "url": "{{origin}}/mcp" }
  }
}

Other MCP clients

Run your own server

git clone https://github.com/openhook-dev/openhook-inbox.git
cd openhook-inbox
uv sync
uv run openhook --http

For stdio, use command uv with args ["--directory", "/absolute/path/to/openhook-inbox", "run", "openhook"]. Keep the HTTP server running to receive callbacks. A locally hosted URL needs public routing for external senders; the hosted service already has it.
