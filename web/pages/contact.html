Billing and account access

Use your account to sign in with GitHub and open the billing portal. Use the portal to manage an existing subscription. If you cannot access your account, contact support with a description of the problem. Never share your GitHub password or a one-time sign-in code. Current plan limits are on the pricing page.

Bugs, contributions and private reports

Use the project issue tracker for reproducible bugs and feature discussions that contain no private data. Use support for security-sensitive reports instead of posting exploit details or credentials publicly. The documentation explains supported operations, and the privacy policy explains retention and deletion. No guaranteed response time or uptime SLA is included in the initial hosted plan.
