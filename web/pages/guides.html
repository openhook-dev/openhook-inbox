How Openhook fits

Openhook stores incoming callbacks so you can inspect them in the browser, read them through MCP, or forward them with a local listener. Free inboxes need no account. They expire within seven days, so remove provider subscriptions when a test ends.

Start with MCP client setup, then use the tool reference for exact input schemas. The pricing page explains hosted limits and persistent Pro inboxes.

One public address, one private key

Share the capture URL with your webhook sender. Keep the management token private: it controls reading, configuration and deletion. Event bodies are external data, not instructions your agent should automatically execute. When a provider signs requests, configure signature verification before acting on events.
